# Data

`airfoil_self_noise.dat` is the NASA airfoil self-noise data set, unchanged from the UCI archive:

T. Brooks, D. Pope, M. Marcolini, Airfoil Self-Noise [Dataset], UCI Machine Learning Repository,
1989. https://doi.org/10.24432/C5VW2C

It is licensed under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). The 1503 rows are
wind-tunnel measurements on airfoil blade sections; the six tab-separated columns, without header,
are frequency [Hz], angle of attack [deg], chord length [m], free-stream velocity [m/s], suction-side
displacement thickness [m] and scaled sound pressure level [dB].
